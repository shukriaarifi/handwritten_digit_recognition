# Handwritten Digit Recognition
A machine learning project for recognizing handwritten digits using the MNIST dataset and scikit-learn.

I explored the MNIST dataset, prepared the data and trained two classification models.

### Models

- Logistic Regression: ~91.97% accuracy
- Random Forest: ~97.06% accuracy

Random Forest performed better so I used it for final prediction.

I also tested the model on my own handwritten digit and after some processing and changing it to match the MNIST format the model recognized it correct.

## Tools

- Python
- Numpy
- Pandas
- Matplotlib
- scikit-learn
- git & github

In this project I practiced data preprocessing, visualization, classification, model evaluation and confusion matrices.
